# Journal des versions

## 0.1.0 — première version publique

**Espaces**
- Parler : dictée (Voxtral), transcription en direct, modes Direct et Affiner, envoi automatique annulable, suggestions apprises.
- Claude : tâches en cours avec étape et temps écoulé, autorisations depuis le téléphone, historique, réponses mises en forme, fichiers modifiés avec différences, reprise des sessions du PC.
- Studio : rédaction de prompt par une IA, questions de précision, relecture par une deuxième IA, envoi.
- PC : mesures, capture d'écran, verrouillage, applications et fenêtres, fichiers, alimentation, bureau à distance, scripts autorisés.

**Sécurité**
- Appairage par code, jeton par appareil, compte Tailscale vérifié, Face ID (passkeys) pour les actions sensibles, 4 niveaux de risque, journal d'audit, clés API dans le coffre Windows, lecteurs bloquables.

**PC**
- Installation en un script, démarrage automatique, icône de notification avec relance de l'agent, mise à jour en un bouton.

**Qualité**
- 10 tests de sécurité sur une copie isolée de l'agent.
